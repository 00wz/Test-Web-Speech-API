# WebSpeech Unity Plugin (WebGL/WebGPU)

## Структура

- `Plugins/JS/WebSpeechPlugin.jslib` — JS-плагин для Web Speech API
- `Assets/Scripts/WebSpeechWrapper.cs` — C#-обёртка для Unity
- `Assets/Scripts/WebSpeechExample.cs` — пример использования

## Интеграция

1. Скопируйте файлы из этих папок в аналогичные папки вашего Unity-проекта.
2. В сцену добавьте пустой объект и повесьте на него компонент `WebSpeechWrapper`.
3. Для использования создайте свой скрипт или используйте пример `WebSpeechExample.cs`:
   - Подпишитесь на событие `OnSpeechRecognized`
   - Вызовите `StartRecognition()`
4. Настройте wake word и длину паузы через публичные поля или методы `SetWakeWord`, `SetPauseMs`.

## Ограничения

- Работает только в WebGL/WebGPU сборке в браузере с поддержкой Web Speech API.
- Wake word ищется в распознанном тексте (не нативный hotword).
- Для работы требуется разрешение на микрофон.

## Сценарий работы

1. Ожидание wake word (например, "ассистент").
2. После обнаружения — распознавание речи до паузы.
3. Полученный текст отправляется в Unity (например, AI-ассистенту).

## Переносимость

- Для переноса скопируйте указанные файлы в новый проект.
- Не требует сторонних зависимостей.
